# 国际化（i18n）

`lakutata/com/i18n`（子包 `@lakutata/i18n`）按**键名**管理各语言的消息：代码里写键名，每种语言在自己的文件里给出这个键的句子。消息使用 [ICU MessageFormat](https://unicode-org.github.io/icu/userguide/format_parse/messages/) 的语法，数字、货币、日期和复数由 Node.js 内置的 `Intl` 按语言格式化，不依赖第三方库。

## 翻译文件

一种语言一个 JSON 文件，文件名是语言标签（BCP 47：`en`、`zh-CN`、`zh-Hant-TW`）：

```
locales/
  en.json
  zh-CN.json
```

```json
{
  "order": {
    "count": "{count, plural, =0 {还没有订单} other {共 # 个订单}}",
    "created": "已为 {customer} 创建订单"
  }
}
```

JSON 的嵌套就是键名的层级：上面的键是 `order.count` 和 `order.created`。键名的每一段都不能包含 `.`。

也可以一种语言一个目录，目录里的文件名（和子目录名）作为键名的前缀：

```
locales/
  zh-TW/
    order.json         → order.*
    admin/user.json    → admin.user.*
```

两种布局可以在同一个目录里混用。

## 配置

```ts
import {Application} from 'lakutata'
import {BuildI18nOptions} from 'lakutata/com/i18n'

Application
    .alias({'@locales': '/path/to/locales'})
    .run(() => ({
        id: 'shop',
        name: 'Shop',
        components: {
            i18n: BuildI18nOptions({
                directory: '@locales',               //支持别名，也可以是数组
                defaultLocale: 'en',                 //默认语言，也是最后的回退语言（默认 en）
                fallback: {'zh-TW': 'zh-CN'},        //可选：繁体缺少的消息用简体的
                currency: 'CNY',                     //可选：{price, number, currency} 的默认货币
                timeZone: 'Asia/Shanghai'            //可选：日期和时间的时区（默认是进程的时区）
            })
        }
    }))
```

| 选项 | 说明 |
|---|---|
| `directory` | 翻译文件所在的目录，可以是多个，支持别名 |
| `locales` | 支持的语言；不写则以加载到的语言为准（加上默认语言） |
| `defaultLocale` | 默认语言，默认 `en` |
| `fallback` | 某种语言缺少消息时，接着去哪些语言里找 |
| `messages` | 直接给出的消息（按语言），在目录之后加载，同名的键会覆盖 |
| `missing` | 缺少消息或参数时：`'throw'` 抛出异常；`'key'` 返回键名（参数原样保留为 `{name}`）并发出一次警告。默认抛出，`NODE_ENV=production` 时返回键名 |
| `currency` | 消息和参数都没有指定货币时使用的货币（ISO 4217） |
| `timeZone` | 日期和时间的时区（IANA） |

## 使用

```ts
import {Inject} from 'lakutata/decorator/di'
import {type I18n} from 'lakutata/com/i18n'

class OrderService extends Provider {
    @Inject('i18n')
    protected readonly i18n: I18n

    public summary(count: number, locale: string): string {
        return this.i18n.t('order.count', {count: count}, locale)
    }
}
```

| 方法 | 说明 |
|---|---|
| `t(key, params?, locale?)` | 某种语言下的消息，用参数格式化；不传语言时使用默认语言 |
| `has(key, locale?)` | 某种语言（或它回退到的语言）是否有这个键 |
| `format(message, params?, locale?)` | 格式化一条不在翻译文件里的 ICU 消息 |
| `translator(locale)` | 得到绑定某种语言的 `Translator`，之后不用每次都传语言 |
| `negotiate(requested)` | 从请求方希望的语言（优先的在前）中选出一种支持的语言，都不支持时用默认语言 |
| `addMessages(locale, messages)` | 运行时添加某种语言的消息，同名的键会覆盖 |
| `getLocales()`、`getDefaultLocale()`、`getKeys(locale)` | 支持的语言、默认语言、某种语言自己的键 |

### 按请求的语言回复

```ts
import {Controller, type HTTPContext} from 'lakutata/com/entrypoint'
import {GET} from 'lakutata/decorator/ctrl'
import {ParseAcceptLanguage, type I18n} from 'lakutata/com/i18n'

class OrderController extends Controller {
    @Inject('i18n')
    protected readonly i18n: I18n

    @GET('/orders/count')
    public async count(): Promise<string> {
        const requested: string[] = ParseAcceptLanguage((this.context as HTTPContext).request.headers['accept-language'])
        const translator = this.i18n.translator(this.i18n.negotiate(requested))
        return translator.t('order.count', {count: await this.countOrders()})
    }
}
```

命令行程序可以用 `EnvironmentLocales()` 读取 `LANG`、`LC_ALL` 等环境变量里的语言（`zh_CN.UTF-8` 会转换为 `zh-CN`）。

`Translator` 还有 `locale`（它的语言）、`has(key)`、`format(message, params)`、`number(value, options)` 和 `date(value, options)`。

## 语言的协商与回退

**协商**（`negotiate`）：依次看请求方的每一种语言，先找完全相同的标签，再找只有语言部分的标签（`en-GB` → `en`），再找同一语言的其他地区（`pt-PT` → `pt-BR`，按支持的语言的顺序）；都找不到时使用默认语言。

**回退**：在某种语言里找不到消息时，依次查找：它在 `fallback` 里配置的语言、去掉最后一段的标签（`zh-Hant-TW` → `zh-Hant` → `zh`）、默认语言。消息总是按**请求的语言**格式化：回退到英文的消息，在德语请求里数字仍然是 `1.000`。

## 消息语法

| 语法 | 例子 |
|---|---|
| 参数 | `你好，{name}` |
| 数字 | `{n, number}`、`{n, number, integer}`、`{n, number, percent}` |
| 货币 | `{price, number, currency}`（货币来自参数 `currency` 或配置）、`{price, number, currency/EUR}` |
| 日期、时间 | `{at, date, short}`、`{at, time, long}`，样式为 `short`、`medium`、`long`、`full`；值可以是 `Date`、时间戳、日期字符串或有 `toDate()` 的对象 |
| 复数 | `{count, plural, =0 {还没有} one {# 个} other {# 个}}`：先匹配 `=数值`，再按该语言的复数规则；`#` 是格式化后的数字；支持 `offset:1` |
| 序数 | `{place, selectordinal, one {#st} two {#nd} few {#rd} other {#th}}` |
| 选择 | `{role, select, admin {管理员} other {用户}}` |
| 转义 | `''` 是一个撇号；`'{literal}'` 原样输出花括号（复数里的 `'#'` 原样输出 `#`） |

`plural`、`selectordinal` 和 `select` 必须有 `other`。消息在第一次使用时解析并缓存，语法错误会指出所在的语言、键和位置，例如 `zh-CN: order.count: the "other" option is required at 1`。

## 键名的类型

应用可以声明键名和它们的参数，之后写错键名或漏掉参数时编译就会报错：

```ts
declare module 'lakutata/com/i18n' {
    interface I18nMessages {
        'order.count': { count: number }
        'order.created': { customer: string }
    }
}
```

没有声明时，`t()` 接受任意键名和参数。

## 异常

| 异常 | 时机 |
|---|---|
| `I18nCatalogException` | 翻译文件或配置无效：JSON 有误、文件名不是语言标签、目录不存在、别名无法解析 |
| `I18nMessageSyntaxException` | 消息的语法错误 |
| `I18nMissingKeyException` | 找不到键（`missing: 'throw'`） |
| `I18nMissingParameterException` | 缺少参数（`missing: 'throw'`），或货币类消息没有可用的货币 |
