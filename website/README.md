# The Lakutata website

The source of [lakutata.com](https://lakutata.com), built with [VitePress](https://vitepress.dev). Most pages come
straight from the repository, so each text lives in one place:

| Section | Source |
|---|---|
| Guides (English and Chinese) | `packages/lakutata/doc/en` and `packages/lakutata/doc/zh` |
| Packages | the `README.md` of each published package |
| API reference | generated by TypeDoc from the type declarations of the `lakutata` subpaths |
| Home pages | `src/index.md` and `src/zh/index.md` |

`scripts/content.mjs` copies these files into `src` before each build. The copies are ignored by git: edit the
originals, not the copies.

## Running it locally

The API reference is read from the built packages, so build them first, at the root of the repository:

```shell
npm run build
```

Then, in this directory:

```shell
npm ci
npm run dev        # http://localhost:5173; after editing a guide or a README, run the content script again
npm run build      # writes the static site to src/.vitepress/dist
npm run preview    # serves the built site at http://localhost:4173
```

`node scripts/content.mjs --no-api` refreshes the guides and the package pages without regenerating the API
reference, which is faster while you write.

## Publishing on GitHub Pages

The workflow `.github/workflows/website.yml` builds the packages and the site, then deploys it to GitHub Pages. It
only runs when started by hand for now. To publish:

1. In the repository settings, under **Pages**, set the source to **GitHub Actions**.
2. Run the **Website** workflow from the **Actions** tab. To deploy on every push to `main`, enable the `push` trigger
   in the workflow.
3. Under **Pages**, enter `lakutata.com` as the custom domain, and turn on **Enforce HTTPS** once the certificate is
   ready.

## The domain

`lakutata.com` needs these DNS records:

| Name | Type | Value |
|---|---|---|
| `@` | A | `185.199.108.153` |
| `@` | A | `185.199.109.153` |
| `@` | A | `185.199.110.153` |
| `@` | A | `185.199.111.153` |
| `www` | CNAME | `lakutata.github.io` |

Optionally, add AAAA records for IPv6: `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153` and
`2606:50c0:8003::153`. Check these addresses against the GitHub Pages documentation when you set them up.

Before adding them, verify the domain in the settings of the `lakutata` account (**Pages**, then **Add a domain**),
which asks for a TXT record. Verification stops anyone else from publishing a site under the domain. Keep the existing
MX record of the mail service, and do not add a wildcard record (`*.lakutata.com`) pointing to GitHub.
